## Overall assessment

The highest-value practices were TDD's failing-first check, blast-radius's caller and wire-format tracing, and executable verification against isolated real services. They produced concrete evidence that would catch regressions. Architect was useful for the migration design; interrogate found real test pollution, and statechart independently demonstrated the toggle counterexample.

The most obvious noise was process disproportionate to the task: an artificial verbose commit for D1, full swarm coordination for two tiny slices, and a formal trail plus review for a small badge. The documentation is useful for an experiment, but not all of that ceremony would earn its cost in routine work. Correct's repeated-mistake workflow was not fully exercised in A3 because the finding was a single observed defect; describing it as a systemic correction would overstate the result. Arena was useful for exploring trade-offs, but three similar candidate designs from the available model family did not provide the intended model diversity.

Cursor-oriented defaults did not transfer completely to Codex. The named Cursor `deslop` and control skills were unavailable; the work used manual diff review and browser automation instead. The configured per-role model slugs and cross-vendor panels were unavailable, so reviewers and swarm workers used the available inherited model. A1 did not execute the full delegated bug-fix playbook, and A3 used two targeted adversaries instead of the full arena. The statechart installer expected `mise`; Java and a downloaded TLC jar provided its documented fallback. These are limits of this run, not evidence that the workflows cannot work outside Cursor.

A few results need care before reuse. C1 changes the API response contract and cannot establish whether unknown external callers exist. C2 starts independently from main and keeps the array response, so it does not include C1's envelope. D2 and D3 show zero before the initial fetch, and their branches retain main's toggle defect. D2's captured browser result is not a portable rerunnable test. The A1 fix exists on its own branch and on A3, not on main.
